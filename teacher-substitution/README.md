# Teacher Substitution Planner

When a teacher is absent, someone has to take their periods. Doing that by hand
every morning means scanning the timetable for who is free, remembering who
covered yesterday, and hoping nobody gets double-booked. This does it in one
click and shows its reasoning.

Open `index.html` in a browser. That's the whole installation — no server, no
build step, no internet connection needed. Data is stored in the browser on that
computer.

## What it does

- **Daily plan** — mark who is away, press *Generate*, and every period they
  would have taught is matched with a free teacher.
- **Manual override** — any row can be changed by hand. Locked rows survive a
  regeneration, so fixing one assignment never scrambles the rest.
- **Uncovered periods are never hidden** — if nobody can take a class, it is
  listed separately with the reason every other teacher was unavailable.
- **Printable notice** — the plan prints as a staffroom sheet, plus a duty slip
  per substitute teacher.
- **Fairness tracking** — saved plans feed a per-teacher substitution count, and
  yesterday's cover pushes a teacher down today's list.
- **CSV in and out** — import the teacher list and timetable from a spreadsheet
  export; export the plan, the timetable, or the workload report.

## How a substitute is chosen

Every teacher who is genuinely free in that period is scored, and the highest
score wins. Ties break on name, so the same input always gives the same plan.

| Factor | Effect |
| --- | --- |
| Teaches the subject | +60 |
| Marked as a reserve teacher | +30 |
| Already takes that class regularly | +20 |
| Each period they teach that day | −8 |
| Each substitution already taken today | −18 |
| Each substitution already taken this week | −12 |

A teacher is excluded outright if they are absent, already teaching, already
covering another class that period, marked unavailable for that slot, or over
their substitution limit.

Two details matter in practice:

- **The scarcest period is filled first.** A period with one free teacher is
  settled before a period with ten, so the only available person is not spent on
  an easy slot and the hard one left uncovered.
- **Limits give way before a class does.** If nobody is within the daily or
  weekly cap, the plan assigns anyway and flags the row *over limit* — an
  unsupervised class is the worse outcome. Turn this off in Settings if the
  caps are contractual.

## Getting your own school in

1. **Settings** — school name, periods per day, working days, substitution
   limits.
2. **Teachers → Import teachers CSV** — columns `Code, Name, Subjects, Reserve`.
   Subjects are separated by `;`. Reserve teachers are floaters preferred for
   cover.
3. **Timetable → Import timetable CSV** — columns
   `Day, Period, Class, Subject, Teacher Code`. Importing replaces the whole
   timetable, and the file is rejected if it double-books a teacher.

`data/teachers.sample.csv` and `data/timetable.sample.csv` show the expected
shape. The app starts with a sample school of 12 teachers and 6 classes so you
can try it before entering real data.

## Daily routine

1. **Absences** — add each teacher who is out, full day or selected periods.
2. **Daily plan** — pick the date, *Generate*, adjust anything you disagree with.
3. **Save plan** — this is what makes the substitution count towards fairness.
4. **Print notice** — for the staffroom board.

## Backups

Everything lives in one browser's local storage. It is lost if browser data is
cleared, and it does not follow you to another computer. **Settings → Download
backup** writes a JSON file; **Restore backup** reads it back. Take one at the
end of each term, and before clearing browser data.

## Development

```
node tests/engine.test.js
```

29 tests covering vacancy detection, candidate eligibility, scoring order,
fairness, cap handling, locked overrides and the sample data.

| File | Purpose |
| --- | --- |
| `js/engine.js` | All scheduling logic. Pure functions, no DOM — this is what the tests exercise. |
| `js/store.js` | Persistence, CSV import, backup/restore. |
| `js/app.js` | Screens and event wiring. |
| `js/seed.js` | Sample school; the timetable is generated by a clash-free allocator. |
| `js/csv.js` | CSV reader/writer (quoted fields, CRLF). |

The engine loads under both `<script>` and `require`, so the code the school
runs is the code the tests check.
